tt988**Extracting response values**
989
990`expected_result.extract` maps a variable name to a JSONPath expression evaluated against
991the JSON response; the value lands in the session's `${variable}` namespace.
992
993```yaml
994expected_result:
995 extract:
996 otp: $.dummy
997 first_title: $.resultObj.containers[0].metadata.title
998```
999
1000The bare form (`resultObj.total`) still works and may include JSONPath array expressions.
