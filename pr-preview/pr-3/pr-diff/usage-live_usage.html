136`press_element ${sign_in_button}`. The new elements join the session only when the instruction
137completes, and `/save` writes them to your elements CSV. AI self-heal is off while the agent
138runs, so every step it takes shows in its history.

185### Secrets are not saved
186
187A value typed into a secret field is not written to disk. Live finds secret fields on the
188screen by their type (a password field), a masked value, or a name, caption, hint or
189locator such as "Password" or "PIN". A value typed without an element goes into the field
190that has focus. When live cannot tell which field that is, a secret field anywhere on the
191screen makes the value secret. The recorded step uses a new element, for example
192`${password_field_value}`, in place of the value. The session keeps the real value, so the
193steps run again in the same session. `/save` writes that element as `<redacted>`, so put
194the real value in the elements CSV before you run the saved test.
